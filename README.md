# 🎁 Sorteio Mágico

Sistema de sorteio de números e amigo secreto desenvolvido com HTML, CSS e JavaScript.

## 🚀 Demonstração

Acesse o projeto online:

https://caiogracogalvao.github.io/Sorteador-AmigoSecreto/

## ✨ Funcionalidades

* 🎲 Sorteio de números sem repetição
* 🎁 Sorteio de amigo secreto
* ✉️ Envio da revelação por e-mail
* 🔒 Impede que alguém tire a si mesmo
* 🔀 Ordem de revelação totalmente aleatória
* 📱 Layout responsivo para desktop e celular
* ✨ Interface temática inspirada em Harry Potter e detalhes de One Piece

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Node.js
* Express
* Brevo API
